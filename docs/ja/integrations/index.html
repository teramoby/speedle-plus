連携

Speedle をアプリケーションおよびインフラストラクチャに接続。

Speedle は認可決定を担当します。アプリケーション、ゲートウェイ、またはプラットフォーム内のポリシー施行ポイント（PEP）が決定ごとに Speedle を呼び出し、結果を適用します。現在、以下のインターフェースがサポートされています。

REST および gRPC API

ポリシー管理サービス (PMS) を通じてサービス、ポリシー、ロールを管理し、認可決定サービス (ADS) にランタイム決定をリクエストします。どちらも REST API を公開しており、サーバー起動時に --grpc-endpoint を指定することで gRPC API を有効にできます。

  • ポリシー管理 API
  • 認可決定 API
  • トークンアサーション Webhook
  • API 概要 (PMS および ADS の proto を含む)

組み込み Go

個別の PMS または ADS プロセスなしで、Go アプリケーション内で直接評価エンジンを実行します。組み込みモードガイドでは、Go モジュールを使用した完全なサンプルを構築します。

SDK

Java、Go、Python、Node.js/TypeScript、Rust、C#/.NET 向けのクライアント SDK が利用可能です。SDK を参照してください。

ポリシーストア

組み込みのファイル、etcd、MySQL、MongoDB ストアを使用するか、別のバックエンド用のストアインターフェースを実装します。ストレージ拡張を参照してください。

以前のガイド

以前の Istio、Kubernetes、Docker のサンプルガイドは公開を終了しました。新しい連携には上記のインターフェースを使用してください。
