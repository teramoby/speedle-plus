# Speedle 旧版彩色标识（存档）

这里保存的是品牌改版前的彩色标识资源。它们原先只存在于
`docs/172c4fea633285df5f8950cdef354c38/images/`（一份历史站点快照目录），
在改版后不再被任何页面引用。为了让素材可检索、不被随快照目录一起删掉，集中到此处存档。

来源：`teramoby/speedle-plus@7160ee2`，`docs/172c4fea633285df5f8950cdef354c38/images/`。
本目录仅为素材存档，**不参与构建，也未被任何页面引用**。
