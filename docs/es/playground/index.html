¿Nuevo en SPDL?Referencia rápida de un minuto+
Escribir una política
grant user alice read book
Use effect, el tipo de principal, el principal, la acción y el recurso. Cada línea es una sentencia. deny deniega el acceso de forma explícita.
Añadir una condición
grant user alice read book if clearance >= 3
Añada un atributo y seleccione su tipo. Use varios valores para crear un array. Cargue el ejemplo de condiciones para probarlo.
Leer el resultado
true — la solicitud está permitida.
false — el acceso se deniega o no se aplica ninguna concesión.
Los errores de entrada y de ejecución se muestran aparte, nunca como false.
