Integraciones

Conecte Speedle con sus aplicaciones e infraestructura.

Speedle toma decisiones de autorización. Un punto de aplicación de políticas (PEP) en su aplicación, puerta de enlace o plataforma llama a Speedle para cada decisión y aplica el resultado. Las siguientes interfaces son compatibles actualmente.

APIs REST y gRPC

Gestione servicios, políticas y roles a través del Servicio de Gestión de Políticas (PMS) y solicite decisiones de tiempo de ejecución del Servicio de Decisiones de Autorización (ADS). Ambos exponen APIs REST; inicie cualquiera de los servidores con --grpc-endpoint para habilitar su API gRPC.

  • API de gestión de políticas
  • API de decisiones de autorización
  • Webhook de aserción de tokens
  • Descripción general de la API (incluidos protos de PMS y ADS)

Go integrado

Ejecute el evaluador dentro de una aplicación Go, sin un proceso PMS o ADS independiente. La guía de modo integrado crea un ejemplo completo con módulos Go.

SDKs

Los SDKs de cliente están disponibles para Java, Go, Python, Node.js/TypeScript, Rust y C#/.NET. Consulte SDKs.

Almacenes de políticas

Utilice el almacenamiento integrado en archivos, etcd, MySQL o MongoDB, o implemente las interfaces de almacenamiento para otro backend. Consulte Almacenamiento conectable.

Guías anteriores

Las guías de ejemplo anteriores de Istio, Kubernetes y Docker ya no se publican. Utilice las interfaces anteriores para nuevas integraciones.
