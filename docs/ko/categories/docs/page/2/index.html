Discord 커뮤니티 참여하기

  • 인가 진단

    인가 평가를 진단하고 결정 이유, 유효한 역할 및 평가된 정책 확인

    인가 평가 프로세스를 진단합니다. 사용자의 리소스 작업이 허용되지 않을 때 그 이유나 어떤 정책이 작업을 거부했는지 조사하는 데 도움이 됩니다.

  • Docker 이미지

    공개된 Speedle 이미지로 speedle-pms, speedle-ads 및 spctl 실행

    Docker Hub 및 GHCR의 단일 이미지로 공유 파일 저장소를 사용하는 정책 관리 서비스, 인가 결정 서비스 및 spctl을 실행합니다.

  • Go SDK

    Speedle Go SDK를 추가하고 로컬 Speedle 또는 Speedle Cloud에 대해 인가 확인 수행

    go get으로 github.com/teramoby/speedle-sdk/go v0.2.0을 추가하고 로컬 Speedle 또는 Speedle Cloud에 대해 IsAllowed 및 Check를 호출합니다.

  • C#/.NET SDK

    Speedle .NET SDK를 추가하고 로컬 Speedle 또는 Speedle Cloud에 대해 인가 확인 수행

    dotnet add package로 Speedle.Sdk 0.2.0을 추가하고 로컬 Speedle 또는 Speedle Cloud에 대해 IsAllowedAsync 및 CheckAsync를 호출합니다.
