유스케이스

Speedle 유스케이스

    애플리케이션 전용 정책

    Alex Chan은 Go로 간단한 애플리케이션을 구현하는 개발자입니다. 인가가 필요하지만 바퀴를 다시 발명하고 싶지 않습니다. Alex는 오픈 소스인 Speedle을 활용할 수 있습니다.

    중앙 집중식 정책 적용 및 관리

    Jin Chen은 다국적 기업의 보안 관리자입니다. 그의 팀은 수십 개의 내부 시스템을 모니터링합니다. 각 시스템의 인가 정책을 한곳에서 효율적으로 관리할 솔루션을 찾고 있습니다.
