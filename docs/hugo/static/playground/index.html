New to SPDL?A one-minute reference+
Write a policy
grant user alice read book
Use effect, principal type, principal, action and resource. Each line is a statement; deny explicitly denies access.
Add a condition
grant user alice read book if clearance >= 3
Add an attribute and select its type. Use multiple values for an array. Load the Conditions example to try it.
Read the result
true — the request is allowed.
false — access is denied or no grant applies.
Input and execution errors are shown separately, never as false.
