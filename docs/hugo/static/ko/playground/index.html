정책 작성
grant user alice read book
effect, 주체 유형, 주체, 동작, 리소스를 사용합니다. 각 줄이 하나의 문입니다. deny는 접근을 명시적으로 거부합니다.
조건 추가
grant user alice read book if clearance >= 3
속성을 추가하고 유형을 선택합니다. 배열로 만들려면 값을 여러 개 사용합니다. 조건 예시를 불러와 시험해 보세요.
결과 읽기
true — 요청이 허용됩니다.
false — 접근이 거부되거나 적용되는 허용이 없습니다.
입력 오류와 실행 오류는 false와 별도로 표시됩니다.
