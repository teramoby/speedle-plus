刚开始使用 SPDL？一分钟快速参考+
编写策略
grant user alice read book
依次填写授权效果、身份类型、身份、操作和资源。每行是一条语句； deny 明确拒绝访问。
添加条件
grant user alice read book if clearance >= 3
添加属性并选择类型；可使用多个值组成数组。加载“条件表达式”示例即可尝试。
查看结果
true — 请求被允许。
false — 明确拒绝访问，或没有匹配的授权策略。
输入与执行错误会单独显示，不会作为 false 授权结果。
