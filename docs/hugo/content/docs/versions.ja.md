## Speedle のリリース

公開されたバージョンとリリースノートについては、[GitHub Releases](https://github.com/teramoby/speedle-plus/releases) ページを参照してください。[v1.6.0](https://github.com/teramoby/speedle-plus/releases/tag/v1.6.0) は、現在の組み込み Go ウォークスルーで固定されているバージョンです。再現可能なモジュール依存関係のために、明示的にリリースされたバージョンを使用してください。[組み込みガイド](../deployment/embedded/) で設定方法を説明しています。

## 以前の Oracle Speedle リリース

バージョン 0.1.0 は、ポリシー管理、認可決定、コマンドラインツール、および統合サンプルを含む最初のオープンソースリリースでした。過去の 0.2.0 計画メモは、現在の Speedle リリースロードマップではありません。
