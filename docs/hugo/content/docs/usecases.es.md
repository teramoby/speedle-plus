## Políticas específicas de la aplicación

Alex Chan es un desarrollador que está implementando una aplicación simple con Go. Su aplicación requiere autorización y no quiere reinventar la rueda. Alex puede utilizar una opción de código abierto como Speedle.

## Gestión y aplicación centralizada de políticas

Jin Chen es el responsable de seguridad de una empresa multinacional. Su equipo supervisa docenas de sistemas internos. Cada sistema usa un mecanismo de autorización y un lenguaje de políticas distintos. Buscan una forma de gestionar todos estos sistemas con eficiencia.

- Gestión centralizada de políticas
- Un modelo de políticas flexible que sirva para todos los sistemas
- Fácil de integrar con sistemas distintos, desde el sistema operativo hasta el middleware y las aplicaciones
- Escalable para dar soporte a todos los sistemas
- Eficiente

## Un único plano de control para la autorización en toda la flota

TTH Inc. es una empresa emergente de nube. Ofrece un entorno nativo de la nube a sus clientes. El entorno se compone de Linux, Docker, Kubernetes e Istio. La seguridad es la prioridad de la oferta de TTH. Definen un modelo de autorización completo y crean políticas en Linux, Docker, Kubernetes e Istio en terminales distintas y con lenguajes de políticas distintos. ¿Se puede simplificar ese trabajo?

- Gestión centralizada de políticas
- Un modelo unificado de políticas de autorización para Linux, Docker, Kubernetes e Istio
- Escalable para la operación en la nube
- Eficiente
- Fácil de integrar con Linux, Docker, Kubernetes e Istio
- Código abierto
