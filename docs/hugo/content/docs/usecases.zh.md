<a id="嵌入到-go-语言编写的应用程序"></a>
## 嵌入 Go 应用

张先生用 Go 开发了一套应用，想加上权限控制。他可以把 Speedle 嵌入应用进程，直接调用 Go API 评估授权请求，无需另起服务。

<a id="利用-speedle-管理应用系统的权限"></a>
## 集中管理应用权限

H 公司正在开发一套远程医疗系统。健康数据属于个人隐私，系统必须严格控制权限，确保每位用户只能访问自己的数据，还要定期接受第三方审计。H 公司可以用 Speedle：

1. 建立兼容 RBAC/ABAC 的授权模型
2. 用易读的 SPDL 编写策略，方便审计人员理解和复核
3. 结合应用审计日志，追踪用户的访问记录

<a id="利用-speedle-集中管理组织内所有信息系统"></a>
## 统一管理多个信息系统

陈先生负责一家大型跨国公司的信息安全。公司过去十年并购了数十家中小型企业，每家被并购公司都有自己的信息系统：JavaEE、Node.js、Ruby on Rails，还有基于 CORBA 的遗留系统。

这些系统的权限机制各不相同。有的把权限写死在代码里，有的使用 JAAS 或 OASIS XACML；策略模型也有 RBAC、ABAC、ACL、黑名单和白名单之分。每次调整权限，陈先生和团队都要登录多个系统，用不同方式修改配置，既繁琐，也容易出错。

Speedle 可以把这些授权决策集中到一套服务中：

1. 用 SPDL 表达 RBAC、ABAC 等授权模型。
2. 通过 REST、gRPC 或 Go API 接入不同技术栈。
3. 集中管理各系统的策略，减少重复配置和不一致。

Speedle 可以管理百万量级的策略，单个实例每秒能处理 3 万到 4 万次授权请求；需要更高吞吐时，增加实例即可横向扩展。

各系统把授权请求交给 Speedle，由 Speedle 返回决策，再由应用执行。这样，团队可以用统一的模型和语言管理权限，同时保留现有应用。
