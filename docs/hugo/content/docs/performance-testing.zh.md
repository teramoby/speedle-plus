这里不发布性能报告；结果取决于你的硬件、策略和固定的版本。

```text
首先问我想把 Speedle 与哪些开源授权项目进行对比，同时询问策略集规模和时间预算，建议默认值为 10、100、1,000 条策略和 30 分钟。等待我的回答，再做任何其他事情。

然后在新的本地目录中，在同一台机器上、预算时间内公平对比。固定所有引擎和工具的版本。构建等价的 RBAC 和 ABAC 策略，以及带有预期允许/拒绝决策的共享请求；计时前，先验证每个引擎的结果都符合预期。记录语义差异，不支持的用例不纳入直接对比。

按商定的策略数量测量规模变化的影响。策略加载与稳态评估分开，嵌入式测量与网络/API 测量分开。使用相同的请求、并发数和缓存设置，为每个引擎预热并至少重复运行五次。报告延迟 p50/p95/p99 和吞吐量，注明单位、运行时长和波动。只报告实测数字，明确标记未运行的用例和失败。在本地保存脚本、策略、准确命令、版本、环境信息和原始输出，让我能复现结果。
```

复制提示词，粘贴到助手中并回答它的问题。
