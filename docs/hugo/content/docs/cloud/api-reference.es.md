Esta página muestra la API pública de Speedle Cloud. El texto de la especificación está en inglés en todos los idiomas de este sitio. Try it out está desactivado, de modo que no se introduce un token de aplicación en el navegador.

El archivo representado es [el subconjunto público incluido en el sitio](/openapi/cloud-public.yaml). Es un marcador de posición de la ruta de comprobación de autorización hasta que Speedle Cloud publique el documento OpenAPI público. No es la especificación completa registrada que enlaza el [índice de la documentación de Cloud](/es/docs/cloud/).

La [vista previa de la API de autorización](/es/docs/cloud/authorization-api/) explica la llamada IsAllowed. [Límites y errores](/es/docs/cloud/limits-and-errors/) enumera las cuotas y las respuestas de error.
