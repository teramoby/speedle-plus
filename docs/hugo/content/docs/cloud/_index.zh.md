Speedle Cloud 是基于开源 Speedle 策略引擎的托管访问控制服务，面向开发者。上线后，你可以在控制台创建服务、编写和导入 SPDL 授权策略与角色策略、在 Playground 中测试授权判定，再从应用服务端调用授权 API，无需自行部署和运维授权服务。

**Speedle Cloud 即将上线。** [cloud.speedle.io](https://cloud.speedle.io/zh-CN/) 的生产环境尚未开放登录。本章节先介绍计划中的使用流程，生产环境开放登录后再补充截图。

请阅读 [Speedle Cloud 快速入门](/docs/cloud/getting-started/)，了解分步操作流程、IsAllowed 请求示例、测试版限额，以及测试版条款和隐私政策的链接。
