## Speedle+ 发布版本

已发布版本及发行说明以 [GitHub Releases](https://github.com/teramoby/speedle-plus/releases) 为准。[v1.6.0](https://github.com/teramoby/speedle-plus/releases/tag/v1.6.0) 是当前嵌入式 Go 示例固定使用的版本。为确保模块依赖可复现，应指定已发布版本；安装方式见[嵌入模式](../deployment-embeded/)。

## Oracle Speedle 历史版本

0.1.0 是原项目首次开源的版本，包含策略管理、授权决策、命令行工具及集成示例。历史文档中的 0.2.0 规划不是当前 Speedle+ 的发布路线图。
