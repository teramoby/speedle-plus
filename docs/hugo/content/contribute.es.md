<a id="uso"></a>
¡Bienvenido a la comunidad Speedle! Estamos muy entusiasmados con su participación y hay múltiples formas de contribuir.

## Promoción

Marque con una estrella [el proyecto en GitHub](https://github.com/teramoby/speedle-plus), recomiéndelo a sus colegas o amigos. También puede compartir sus historias de éxito con nosotros.

<a id="discusion-y-comunidad"></a>
## Discusión y comunidad

Únase a la [comunidad de Discord de Speedle](https://discord.gg/uaY2xVsbbT) para hacer preguntas, compartir ideas y discutir contribuciones.

Únase a nuestros grupos [speedle-users](https://groups.google.com/forum/#!forum/speedle-users) y/o [speedle-developers](https://groups.google.com/forum/#!forum/speedle-developers).

<a id="issues"></a>
## Problemas

Presente un [GitHub issue](https://github.com/teramoby/speedle-plus/issues) para cualquier error o mejora.

Por favor incluya:

1. Versión de Speedle
2. Descripción del problema
3. Entorno y pasos reproducibles
4. Comportamiento esperado

<a id="code"></a>
## Código

Las contribuciones a Speedle se realizan bajo la Universal Permissive License 1.0 (UPL-1.0). Firme sus commits (`git commit -s`) para certificar que tiene derecho a enviar su contribución según el Developer Certificate of Origin (DCO) 1.1. Conserve los avisos de derechos de autor y licencia existentes e identifique cualquier material de terceros en su Pull Request.

Siga el proceso a continuación para contribuir:

1. Firme cada commit con `git commit -s` (consulte [DCO](https://github.com/teramoby/speedle-plus/blob/master/DCO) y [UPL-1.0 LICENSE](https://github.com/teramoby/speedle-plus/blob/master/LICENSE))
2. Haga un fork del repositorio
3. Solucione un problema existente o cree un issue y soluciónelo
4. Cree un Pull Request que solucione el problema
5. Revise los resultados de la canalización de CI y corrija cualquier falla
6. Revisaremos su PR y lo fusionaremos según corresponda

## Código de conducta

Siga la [Regla de Oro](https://en.wikipedia.org/wiki/Golden_Rule) y consulte el [Código de Conducta de Contributor Covenant](https://www.contributor-covenant.org/version/1/4/code-of-conduct.html) para obtener pautas específicas.
