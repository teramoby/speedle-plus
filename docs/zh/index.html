关于 Speedle

权限控制，
独立于应用代码。

Speedle 是面向云原生与传统应用的通用权限控制引擎，为用户、服务和委托进程评估 RBAC 与 ABAC 授权策略。

一个引擎，连接多种技术栈

统一定义并集中管理授权策略，让不同语言和服务都能通过 Speedle 获得一致的授权决策。

开源设计，灵活扩展。 Speedle+ 采用 Universal Permissive License，持续推进项目发展。
