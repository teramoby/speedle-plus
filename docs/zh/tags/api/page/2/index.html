  • Java SDK

    添加 Speedle Java SDK，向本地 Speedle 或 Speedle Cloud 发起授权检查。

    用 Maven 或 Gradle 添加 io.speedle:speedle-sdk 0.1.0，再向本地 Speedle 或 Speedle Cloud 调用 isAllowed 与 check。

  • Python SDK

    添加 Speedle Python SDK，向本地 Speedle 或 Speedle Cloud 发起授权检查。

    用 pip 或 uv 安装 speedle 0.1.0，再向本地 Speedle 或 Speedle Cloud 调用 is_allowed 与 check。

  • Node.js/TypeScript SDK

    添加 Speedle Node.js/TypeScript SDK，向本地 Speedle 或 Speedle Cloud 发起授权检查。

    @speedle/sdk 0.1.0 发布后用 npm 安装，再向本地 Speedle 或 Speedle Cloud 调用 isAllowed 与 check。
